One line, max 140 characters — the robot vacuum's excuse for missing a spot.

> I didn't miss that spot. I was giving the dust a head start, it's called strategy, not laziness.

`main.ts` writes that exact line (96 characters, no trailing newline) to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-vacuum-excuse-out node main.ts
```
